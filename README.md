# Folder access

一个 DSH（DeepSeek Harness）插件：在左侧栏提供「文件夹访问」面板，用来配置 DSH 工具可以访问的文件夹**白名单**与**黑名单**，并在每次工具调用时强制执行。

## 功能

- 左侧栏图标 → 中央「文件夹访问」页面。
- **白名单**：非空时，只允许访问这些文件夹及其子文件夹。
- **黑名单**：始终拒绝这些文件夹及其子文件夹，优先于白名单。
- **总开关**：关闭时完全放行（等同于不安装拦截器）。
- **检查路径**：按当前策略试算一个路径，显示允许/拒绝与命中规则。
- **最近拦截**：显示本次启动后最近的拦截记录（工具、路径、命中规则）。
- 策略保存在 `$DSH_HOME/folder-access-policy.json`（默认 `~/.dsh/folder-access-policy.json`），保存即生效，跨会话、跨工作区一致。

## 使用

1. 安装后刷新 Web 页面（F5），左侧栏面板列表末端会出现文件夹图标「文件夹访问」。
2. 打开总开关「启用限制」，然后添加白名单/黑名单文件夹（只接受绝对路径，例如 `D:\work`；也可用「选择文件夹…」）。
3. 启用白名单前，如果当前工作区不在白名单内，页面顶部会出现黄色警告和「把当前工作区加入白名单」按钮——否则本会话的文件工具会立即全部被拒绝。
4. 「检查路径」可以按当前策略试算任意路径；「最近拦截」显示本次启动后的拦截记录。

## 强制方式

插件注册一个全局 `ctx.tools.guard()`：

- 文件类工具（`read` / `write` / `edit` / `glob` / `grep` / `read_image` / `present` / office / lsp 等）按参数中的路径检查；相对路径按该会话的工作目录解析；`glob` / `grep` 未给路径时使用会话工作目录。
- shell 工具（`pwsh` / `bash`）按命令文本里的绝对路径、以及该次调用的工作目录检查。
- 符号链接/联接点会先解析成真实路径再比对，避免用链接绕过策略。
- 策略文件被外部修改后会按修改时间自动重新加载；文件写坏时保留上一份有效策略并在面板提示。

## 限制

- **只收紧、不放开**：白名单不会覆盖 DSH 自身的沙箱模式；沙箱拒绝的写入，本插件也不会放行。
- 工具调用层拦截，不是操作系统级隔离：蓄意绕过（例如在脚本内部拼接路径、调用其他程序、`cordis_run` 动态代码）无法被完全阻止。
- 黑名单优先于白名单；两者同时命中时拒绝。

## 文件

- `index.js`：Host 半边（策略读写、工具守卫、`/api/folder-access/*` 桥接路由）。
- `client.js`：浏览器半边（侧栏图标与配置页面）。
- `cordis.patch.yml`：插入 `folder-access` 插件行。
- `locale/*.json`：插件管理器的标题与描述。
- `icon.svg`：插件图标。
